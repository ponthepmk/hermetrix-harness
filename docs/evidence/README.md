# Local experiment evidence

New experiment captures and generated example projects in this directory stay
on the local machine and are ignored by Git. This includes raw model requests
and responses, copied source trees, trial applications and execution logs.
Previously tracked historical evidence remains in Git.

The Harness source and standing test fixtures under `internal/` remain versioned.
Portable summaries of the current validation are in
[`docs/validation/`](../validation/). Detailed local reports can reference files
below this directory, but those captures are not part of a fresh clone.
