# เชื่อมบัญชีและส่งคอนเทนต์จาก Hermetrix

อัปเดต 2026-09-26 · schema 65 (social publishing เพิ่มใน v57–v59, v62–v63)

## สิ่งที่ต้องเตรียม

1. มี Facebook Page หรือ TikTok account ที่เป็นปลายทางจริง และมีแอปนักพัฒนาพร้อม access token ของบัญชีนั้น การล็อกอินใน browser อย่างเดียวไม่ให้สิทธิ์ API สำหรับโพสต์
2. Facebook: ใช้ **Page access token** ของ Page ที่ต้องการส่ง ขณะเชื่อม Hermetrix อ่าน `/me?fields=id,name,category` เพื่อยืนยัน Page; สิทธิ์เผยแพร่จริงตรวจได้เมื่อเริ่มส่งออก หากแพลตฟอร์มปฏิเสธ ระบบเก็บผลและไม่ส่งซ้ำเอง
3. TikTok Direct Post: ให้แอปและผู้ใช้ grant `video.publish`; Hermetrix อ่าน creator-info ล่าสุดก่อนแสดงตัวเลือกการมองเห็น แล้วตรวจชื่อบัญชี ตัวเลือก และความยาววิดีโออีกครั้งก่อนส่ง [เอกสารทางการ](https://developers.tiktok.com/docs/en/content-posting-api-reference-query-creator-info)
4. TikTok ส่งเป็นร่าง: ใช้ token ที่มี `user.info.basic` สำหรับยืนยันบัญชี และ `video.upload` สำหรับการส่งร่าง สิทธิ์ upload ยืนยันกับ TikTok เมื่อเริ่มส่งหลังอนุมัติ เจ้าของบัญชีต้องเปิดการแจ้งเตือนใน TikTok ตั้งคำบรรยาย/การมองเห็น/ป้าย AI และเผยแพร่ต่อเอง [เอกสารทางการ](https://developers.tiktok.com/docs/en/content-posting-api-reference-upload-video)
5. วิดีโอต้องเป็น MP4 หรือ WebM ที่ Hermetrix ตรวจชนิดและอ่านเล่นได้ ระบุสิทธิ์และที่มาของสื่อก่อนอนุมัติร่าง

## ทำในแอป

1. เปิด **เครื่องมือและการเชื่อมต่อ → Facebook Page และ TikTok** เลือกแพลตฟอร์มและเส้นทาง TikTok แล้ววาง token ในช่องรหัสลับ กดยืนยันการตรวจบัญชี หน้าจอจะแสดงชื่อบัญชีและสถานะ โดยไม่คืนค่า token
2. เปิด Task → **ทำคอนเทนต์จากแหล่งข้อมูล** → **บอกเรื่องที่จะทำ** กรอกหัวข้อ กลุ่มผู้อ่าน และภาษา เลือก Facebook Page/TikTok ที่เชื่อมไว้จากรายการแนะนำ หรือพิมพ์ชื่อที่ตรงกับบัญชีจริง แล้วบันทึก ตัวอย่าง: หัวข้อ “AI ช่วยร้านเล็ก” กลุ่มผู้อ่าน “เจ้าของร้าน” ภาษา “ไทย” การบันทึกขั้นนี้ยังไม่โพสต์อะไร
3. ค้นบทความ เลือกแหล่ง อ่านต้นฉบับ ตรวจข้อกล่าวอ้าง หากเป็นประเด็นสำคัญให้เลือกบทความคนละชิ้นเป็นแหล่งที่สองและใส่หลักฐานแยกกัน จากนั้นสร้าง/เลือกวิดีโอ และบันทึกร่างของแต่ละปลายทาง
4. ตรวจร่างและอนุมัติ **แต่ละร่าง** การอนุมัติร่างยังไม่ส่งอะไรออก
5. ในขั้น **ตรวจและส่งออกแต่ละชิ้น** กดตรวจตัวเลือกของบัญชี TikTok ก่อน เลือกการมองเห็นที่บัญชีนั้นอนุญาต ตัดสินใจเปิดความคิดเห็น/Duet/Stitch และระบุว่าเป็นสื่อ AI หรือเชิงพาณิชย์หรือไม่ สำหรับ Direct Post ต้องยืนยันข้อกำหนดการใช้เพลงก่อนเตรียมตัวอย่าง จากนั้นตรวจข้อความ วิดีโอ บัญชี และตัวเลือก แล้วอนุมัติ **คำสั่งส่งออกชิ้นนั้น** [แนวทางหน้าส่งออกของ TikTok](https://developers.tiktok.com/docs/en/content-sharing-guidelines)
6. กด **อัปโหลดและเผยแพร่** หรือ **อัปโหลดเป็นร่าง** เฉพาะชิ้นที่ต้องการ แล้วใช้ **ตรวจสถานะจริง** จนแพลตฟอร์มตอบผลสุดท้าย

## ผลลัพธ์และการกลับมาทำต่อ

- `เผยแพร่แล้ว` ต้องมาจากการตรวจสถานะบนแพลตฟอร์ม ไม่ใช่แค่การอัปโหลดสำเร็จ
- `ส่งเป็นร่าง` ยังไม่ถือว่าเผยแพร่หรือปิด Task ได้; TikTok อาจเปลี่ยนเป็น `PUBLISH_COMPLETE` หลังเจ้าของบัญชีเผยแพร่ต่อ [สถานะทางการ](https://developers.tiktok.com/docs/en/content-posting-api-reference-get-video-status)
- `ผลยังไม่แน่นอน` หมายถึงอาจมีผลบนแพลตฟอร์มแล้ว Hermetrix จะไม่สร้างรายการใหม่ซ้ำ ให้ตรวจสถานะจากรหัสที่แพลตฟอร์มให้ หรือเปิดบัญชีจริงเพื่อตรวจ หากไม่มีรหัส remote ให้ตรวจบนแพลตฟอร์มก่อนทำรายการใหม่
- หากแพลตฟอร์มตอบว่าไม่สำเร็จแน่ชัด ให้แก้ปัญหาที่แสดงแล้วกด **เตรียมส่งใหม่หลังแก้ปัญหา** ประวัติครั้งเดิมยังอยู่ คำสั่งครั้งใหม่ต้องตรวจและอนุมัติใหม่ก่อนส่ง
- การแก้ brief, ข้อกล่าวอ้าง, ร่าง หรือสื่อ ทำให้การอนุมัติเดิมใช้กับฉบับใหม่ไม่ได้
- ชื่อบัญชีและสถานะอยู่ในฐานข้อมูล; access token และ URL อัปโหลดที่อาจมีความลับอยู่ใน vault ของเครื่อง
- TikTok Direct Post ของแอปที่ยังไม่ผ่าน audit อาจส่งได้เฉพาะการมองเห็นส่วนตัว และตัวเลือกเนื้อหาแบรนด์ต้องเป็นสาธารณะหรือเพื่อน หากตัวเลือกไม่เข้ากัน ระบบจะไม่ส่ง Direct Post ให้ใช้เส้นทางร่างเมื่อบัญชีมีสิทธิ์นั้น [ข้อกำหนด TikTok](https://developers.tiktok.com/docs/en/content-sharing-guidelines)
- ในหน้า **Artifacts** ของวิดีโอ กดดูหลักฐานภาพและเสียงเพื่อถอดเฟรมสามช่วงและถอดคำพูดพร้อมเวลา เครื่องนี้มี Whisper model ในเครื่องแล้ว; เครื่องอื่นตั้ง `HERMETRIX_WHISPER_CLI` และ `HERMETRIX_WHISPER_MODEL` ให้ชี้ไฟล์ local ก่อนใช้ ผลถอดคำพูดอาจผิดและต้องเปิดวิดีโอเทียบตามเวลาที่แสดงก่อนนำไปเขียน

## ขอบเขตการตรวจแล้ว

ทดสอบ Facebook Feed, Facebook Reel, TikTok Direct Post และ TikTok draft upload กับ API จำลองที่ตรวจ request/bytes/status จริง ทดสอบ real Chrome สำหรับหน้าเชื่อมบัญชีและ flow Task และทดสอบ Comfy สร้าง MP4 ในเครื่องแล้ว การเผยแพร่ไปบัญชีจริงต้องมี token/grant ของผู้ใช้และการอนุมัติคอนเทนต์ชิ้นนั้น จึงยังไม่มี remote receipt จากบัญชีจริงในรอบนี้
